# 电脑游戏包服务器（Windows）

本模式把创作中心和游戏包 API 运行在你自己的电脑上，游戏包写入项目目录 `data/game-packages/`，不使用 Vercel 的临时文件系统。

## 启动

1. 在 Windows 电脑安装 Node.js LTS。
2. 下载/克隆本项目，并在项目根目录保留完整源码。
3. 双击 `scripts\\start-local-server.bat`。
4. 首次运行会安装依赖、生成随机访问口令、构建并启动服务。请保存终端显示的口令。
5. 电脑浏览器打开 `http://localhost:3000/design`，在创作中心点“保存到电脑游戏包目录”，输入口令。
6. 在游戏中心输入同一口令并连接，即可读取电脑存档。

## 存储与安全

- 游戏包位于 `data/game-packages/<游戏ID>.json`，停止/重启服务不会删除这些文件。
- 访问口令保存在项目根目录的 `.local-game-store-token`；该文件已加入 Git 忽略规则。
- 列表、写入和删除 API 都要求口令。不要把口令提交到 Git。
- 目前游戏中心提供从电脑存档下载到当前设备的功能；它不会自动把浏览器中已有的游戏批量上传。
- 这个模式的电脑端本机地址是 HTTP。**iPhone 通过局域网 HTTP 打开时，浏览器可能不允许 GPS 定位。** 手机实测需要后续配置可信 HTTPS 入口（例如安全的 HTTPS 隧道）并验证后，才算完整通过。
- 不要直接把此服务暴露到公网，也不要把访问口令发给不可信的人。若需要远程/手机访问，应先配置 HTTPS 与网络访问限制。

## 故障处理

- 若 3000 端口已被占用，先关闭之前运行的 MOS Scene Hunt 窗口。
- 若构建失败，脚本会停止；`data/game-packages/` 中的游戏包不会被清理。
- 若忘记口令，可在服务停止后查看项目根目录的 `.local-game-store-token`。删除该文件会在下次启动时生成新口令，旧浏览器会话需重新连接。
