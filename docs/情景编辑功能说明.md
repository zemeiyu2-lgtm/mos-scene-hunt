# 情景编辑功能说明（第一批）

## 目标
在原有设计流程内加强情景编辑，不另造一套复杂流程。AI 快速生成和人工精细设计共用同一编辑器；AI 不是必需步骤，设计者始终可以逐项修改。

## 当前改进
- 情景内容：分别编辑到达后故事、前往地点时的提示、玩家任务指令。
- 现场图片：使用现有媒体编辑器添加真实地点照片；题目图片可在题目区域单独添加。
- 题型：支持选择题、文本答案题、关键词题。
- 答案：选择题编辑选项和正确答案；文本/关键词题每行填写一个可接受答案。
- 反馈：编辑卡住时的提示和答对后的故事反馈。

## 设计者操作顺序
1. 选择一个场景。
2. 写下玩家到达后会看到的情景。
3. 添加现场真实照片。
4. 写清楚玩家要做什么。
5. 选择题型，填写问题和答案。
6. 添加提示与答对后的反馈。
7. 设置奖励线索。
8. 保存并进入手机试玩，检查玩家实际看到的内容。

## 设计原则
- 文字简单直接，全年龄玩家都能理解；避免长篇文学化叙述。
- 题目尽量与现场实物、照片、标志或故事有真实关系。
- 不强制玩家拍照或收集无关人员的个人信息。
- 游戏任务原则上全部在开放、安全、获准使用的户外区域完成，不要求进入建筑物。
- AI 生成内容必须由设计者检查事实、答案、现场安全和奖励兑现条件。
- 图片编辑可用不代表导入、导出和分享链路已完整验收，必须单独测试。

## 首批验收清单
- [ ] 可编辑情景故事、前往提示、玩家任务指令。
- [ ] 可添加和替换现场图片与题目图片。
- [ ] 可切换选择题、文本答案题、关键词题。
- [ ] 可编辑选项、正确答案或多个可接受答案。
- [ ] 可编辑提示和答对后的故事反馈。
- [ ] 保存后重新打开，内容仍然存在。
- [ ] 手机端试玩时，题目、答案判定、图片和反馈表现正确。
- [ ] 导出再导入后，图片与情景内容保持完整。
- [ ] 真实场地与坐标经过现场核实，任务不要求进入室内。
