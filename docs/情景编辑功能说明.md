# 情景编辑功能说明（第一批）

## 目标

在原有设计流程内加强情景编辑，不另造一套复杂流程。AI 快速生成和人工精细设计共用同一编辑器；AI 不是必需步骤，设计者始终可以逐项修改。

## 当前改进

### 情景内容
- 到达后故事：玩家抵达现场后看到的简短情境。
- 前往地点时的提示：玩家前往地点时看到的说明。
- 玩家任务指令：明确告诉玩家要观察、判断或完成什么。
- 现场图片：通过媒体编辑器添加真实地点照片；题目图片可单独添加在题目区域。

### 题目与反馈
- 支持选择题、文本答案题、关键词题三种现有题型。
- 选择题可编辑选项和正确答案。
- 文本答案题与关键词题可填写多个可接受答案，每行一个。
- 可填写卡住时的提示。
- 可填写答对后的故事反馈，让过关结果推进故事，而不只显示“正确”。

## 设计者操作顺序

1. 选择一个场景。
2. 写下玩家到达后会看到的情景。
3. 添加现场真实照片。
4. 写清楚玩家要做什么。
5. 选择题型，填写问题和答案。
6. 添加提示与答对后的反馈。
7. 设置奖励线索。
8. 保存并进入手机试玩，检查玩家实际看到的内容。

## 设计原则

- 文字简单直接，全年龄玩家都能理解；避免长篇文学化叙述。
- 题目尽量与现场实物、照片、标志或故事有真实关系。
- 不强制玩家拍照或收集无关人员的个人信息。
- 游戏任务原则上全部在开放、安全、获准使用的户外区域完成，不要求进入建筑物。
- AI 生成的内容必须由设计者检查事实、答案、现场安全和奖励兑现条件。
- 图片和媒体资源在导入、导出与分享流程中的完整性仍需单独测试；编辑器能选择图片，不等于所有打包路径都已验收。

## 第一批验收清单

- [ ] 可编辑情景故事、前往提示、玩家任务指令。
- [ ] 可添加和替换现场图片与题目图片。
- [ ] 可切换选择题、文本答案题、关键词题。
- [ ] 可编辑选项、正确答案或多个可接受答案。
- [ ] 可编辑提示和答对后的故事反馈。
- [ ] 保存后重新打开，内容仍然存在。
- [ ] 手机端试玩时，题目、答案判定、图片和反馈表现正确。
- [ ] 导出再导入后，图片与情景内容保持完整。
- [ ] 真实场地与坐标经过现场核实，任务不要求进入室内。
