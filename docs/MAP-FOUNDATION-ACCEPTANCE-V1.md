# 地图基础架构与验收标准 V1.0

## 本阶段目标

稳定手机端真实世界寻宝的地图基础，同时避免底图服务商或地图引擎锁定项目。当前仅使用 OpenStreetMap 标准瓦片；本阶段不迁移 Leaflet，不启用未经确认适用条件的其他公共瓦片服务。

## 架构原则

1. **底图与游戏逻辑分离**：玩家定位、场景标记、寻宝范围、触发半径、任务状态和目标提示由 MOS 自己绘制与管理。
2. **服务配置集中**：瓦片 URL、版权标注、最大缩放等级集中放在 `lib/map/tiles.ts`，不得在页面或游戏逻辑中散落硬编码。
3. **可替换而非绑定**：未来更换瓦片服务或评估 MapLibre 等引擎时，不应重写 GPS 判定、场景数据或任务状态。
4. **默认安全**：未知或过期的本地底图设置必须回退到已批准的默认底图。
5. **尊重服务条款**：显示可读的版权标注；遵守服务端缓存指示；不得从 OSM 公共瓦片服务器批量预取或下载离线瓦片。
6. **离线边界清楚**：游戏内容缓存不等于底图离线缓存。不得宣传当前版本支持离线地图瓦片。

## 当前决策

- 地图引擎：Leaflet 1.9，暂不更换。
- 默认底图：`https://tile.openstreetmap.org/{z}/{x}/{y}.png`。
- 版权标注：`© OpenStreetMap contributors`，由 Leaflet attribution 控件显示。
- 暂不向玩家提供 HOT / CARTO 切换选项。重新启用其他服务前，必须先核对最新服务条款、密钥要求、配额、署名与可用性。
- 不新增地图依赖，不在本阶段增加付费服务。

## 验收清单

### 配置与兼容
- [ ] 默认底图使用 OSM 官方标准瓦片 URL。
- [ ] 未知 provider ID 能回退到 OSM 标准底图。
- [ ] 旧设备中保存的 HOT / CARTO 偏好不会导致游戏继续加载未批准服务。
- [ ] 现有游戏内容、场景坐标、GPS 距离与触发判定不因底图调整而变化。

### 地图显示
- [ ] 地图可正常加载；加载失败时不得造成游戏页面崩溃。
- [ ] OSM 版权标注始终可见、清楚可读，不被顶部 HUD 或底部操作面板遮挡。
- [ ] 玩家位置与精度范围、场景标记、当前目标、触发范围和游戏区域均继续显示。
- [ ] 回到我的位置、缩放、拖动地图和设计者地图编辑功能正常。

### 手机体验
- [ ] 320px、375px、390px 及常见桌面宽度下，顶部控件不溢出。
- [ ] 地图控件不遮挡核心任务信息与到达操作。
- [ ] iOS Safari 与 Android Chrome 的基本地图交互可用。
- [ ] GPS 权限拒绝、定位等待、模拟定位和真实定位状态均有清楚提示。

### 验证与发布边界
- [ ] 通过 `npm run typecheck`。
- [ ] 通过 `npm test`。
- [ ] 通过 `npm run build`。
- [ ] 通过 `npm run test:acceptance`；若环境不支持，记录具体原因，不得标记通过。
- [ ] 在手机真实浏览器检查地图瓦片、署名和布局。
- [ ] 本分支验证完成前，不合并到 `master`，不部署生产。
