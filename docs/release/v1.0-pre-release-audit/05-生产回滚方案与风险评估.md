## 2. 六个必答问题

**Q1 新部署首页异常，如何恢复旧部署？**
Vercel 控制台 Deployments → 旧部署 → **Promote/Rollback to Production**（或 `vercel rollback <old-dpl>`）。Alias 会立即指回旧部署，分钟级生效。

**Q2 如何确认旧部署仍存在且可恢复？**
`vercel ls --prod` 列表中旧部署状态为 ● Ready；`vercel inspect <old-url>` 返回正常。回滚前必须先执行这两步。

**Q3 恢复 Alias 是否恢复旧环境变量构建产物？**
**会恢复旧 bundle，不会改变当前环境变量配置。** 环境变量属项目级配置，Alias 切换只是改流量指向。旧 bundle 的模拟器开关由**它构建时**的变量快照决定，与现在 env 面板里的状态无关。

**Q4 旧部署是否仍包含 GPS 模拟器风险？**

- `kcc5lwyok`（更早的 admin-platform 线）：构建于该变量存在之前，bundle 应无模拟器；但其内容不含本轮整合（管理后台存储线等），且无自动演示能力。

**Q5 回滚后是否需要临时措施？**
