## 3. 五个必答问题

**Q1 现在是否已具备生产部署的技术条件？**
是。候选代码锁定、隔离组合构建与关键测试全部通过；剩余为环境变量操作与部署后核验等**程序性前置条件**，非技术障碍。

**Q2 删除旧 GPS 模拟器变量是否会影响真人 GPS？**
不会。真人定位唯一入口 `lib/location/provider.ts` 直接使用 `navigator.geolocation`，不读取任何环境变量；组合构建实测真人定位代码路径正常。

**Q3 自动演示是否可以独立于 DEV 模拟定位器运行？**
可以。演示能力由 `NEXT_PUBLIC_ENABLE_AUTO_DEMO=1` 门控，fix 由演示组件经纯函数 `simulateFix` + `injectFix` 专用通道自产；无 SIMULATOR 的组合构建中演示完整跑通，DEV 面板确认不存在。

**Q4 如果部署失败，回滚是否会重新引入旧安全风险？**
会（视回滚目标）。今晨 5 个生产部署均构建于 SIMULATOR=1 期间，回滚到其中任一都会恢复玩家可用的 DEV 模拟面板；且回滚后删除的环境变量不影响旧 bundle。回滚必须按 05 号文档标记为「安全降级」并记录回滚后安全状态。回滚到更早的 `kcc5lwyok` 无模拟器风险但功能大幅回退。

**Q5 现在还需要项目负责人批准哪些具体操作？**
见 §4 授权清单；最小集合为：两类环境变量操作 + 一次生产部署 + 部署后核验执行。
