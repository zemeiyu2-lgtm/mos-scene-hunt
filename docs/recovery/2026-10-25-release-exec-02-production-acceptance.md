### 通过项（实测）

- 0 测试 ID 预先不存在（404）；1 首次发布 201/`created=true`/`playPath=/select#cloud=id.version`；2 **跨请求读取 latest 正确**（持久化，非内存/临时文件系统）；3 指定版本读取 200 + `immutable` 缓存头 + 内容正确；4 同内容不同键序重复发布幂等（`created=false`，无假 409）；5a 新版本 201；5b/5d 旧版本内容始终不变；5c latest 传播 10 秒内；6a/6b 404（`game_not_found`/`version_not_found`）；6c/6d/6g 400/415 校验拒绝；6f 路径逃逸 ID 400；7 错误响应无内部路径/堆栈；8 `/select` 200。
- 复测：写入后版本首读延迟 ≈781ms（第二次发布实测）；第二测试游戏跨请求读取正确。

### 发现的问题（如实记录，均未阻塞发布）

1. **瞬时读不一致（已证实一次）**：首次发布后立即读取 `?v=` 版本对象返回 404（`version_not_found`），约 30 秒后同 URL 恢复 200 且内容正确。判断为 Vercel Blob 写入后跨区复制延迟（函数 iad1、store sin1）。影响面：发布后极短时间内打开分享链接可能看到"版本不存在"提示；数据本身无损。建议后续（下一阶段）在读取端对 `BlobNotFoundError` 做一次短重试。
2. **伪造 Content-Length 请求挂起连接**：`Content-Length: 1` + 300KB body 的 POST 使连接长时间无响应（30 秒无返回，未产生错误状态码）。属 HTTP 层既有行为（非本阶段引入、非持久化故障），有慢速攻击面。建议后续在读取 body 前增加实际字节数校验的防挂起处理或依赖平台请求超时。按停止条件未反复重试该请求。
